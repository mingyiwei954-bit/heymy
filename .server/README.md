# 点赞计数服务

启动：`python3 server.py --root .. --port 8768`

使用 SQLite 持久化总数，数据库默认位于服务目录的 data/likes.sqlite3。静态网站根目录之外保存数据，请备份该文件。运行环境仅需要 Python 3，无第三方依赖。

线上部署时保持监听 127.0.0.1，以 systemd 管理进程，并在 ev0331 的 Nginx 虚拟主机中将 /api/likes 代理到该服务。其余静态页面继续由 Nginx 提供。前端每 60 秒提交待同步点击并刷新全站总数，退出页面时尝试发送尚未同步的点击；网络失败时暂存在浏览器等待重试。每次普通区域有效点击计一次，自动生成的装饰爱心不计数。

接口：GET /api/likes 返回 total；POST /api/likes 接收 UUID id 与 1–200 的整数 count，相同 id 重试不重复累计。它是互动点击总数，不是独立访客人数。公共接口可被脚本提交，正式上线可在 Nginx 为此路径加合理的请求限流。
